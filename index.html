Tambah Foto ke Galeri

Foto disimpan permanen di folder repo

  1. Upload foto
    Ke folder photos/ di GitHub
    Buka folder photos →
  2. Edit data.json
    Tambahkan entri seperti ini: 
    {
  "src": "photos/nama-file.jpg",
  "desc": "",
  "date": "2026-10-17"
}
    desc & date boleh dikosongkan
  3. Commit & push
    Vercel akan update otomatis dalam 1–2 menit

Atau kirim fotonya ke Rafer, nanti diupload ke repo 💕
